# Paper Margins — 論文の余白に、理解を残す

PDFを読みながらChatGPTに質問し、質問と回答を論文の対応箇所へ注釈として保存する、Chrome / Edge向けの拡張機能です。現在のバージョンは **1.3.1** です。

**このプロジェクトの独自コード、UI、READMEおよびドキュメントは、ユーザーの指示に基づいてGPT（ChatGPT / Codex）が作成・修正しました。** PDF.js、KaTeXなどの同梱ライブラリは、それぞれの開発者による成果物です。

## できること

- PDF Viewerと同じPDF.js標準ビューアを内蔵し、検索・目次・サムネイル・回転・拡大表示を使う。
- 複数のPDFを別々のブラウザタブで同時に開き、切り替えて読む。
- PDFを縦にスクロールして読み、本文や数式・図の範囲を選択する。
- PDF上へペンで手書きし、色・太さを変更する。書き込みを自動保存し、PDFにも出力する。
- 選択した本文・ページ番号・質問をChatGPTの入力欄へ入れる。数式・図は切り抜きPNGも準備する。
- 質問と回答を選択箇所の注釈へ保存し、あとから読み返す。タグ付け・検索・数式表示に対応する。
- 回答の自動取得が失敗した場合、コピーした本文を貼り付けて保存する。
- PDF本体と注釈をJSONでバックアップ・復元し、元の箇所に番号を付け、会話の全文をPDF末尾へ書き出す。

OpenAI API・APIキー・独自サーバーは使いません。この拡張機能自身によるAPI課金はありません。ChatGPTは利用者自身のアカウントで使用し、ChatGPT側のプラン料金・利用制限は通常どおり適用されます。

## インストール

デスクトップ版Chrome / Edge **142以降** が対象です。ChatGPTへのログインが必要です。

1. GitHubの **Code → Download ZIP** で、このリポジトリをダウンロードして展開します。
2. Chromeで `chrome://extensions` を開きます。Edgeでは `edge://extensions` です。
3. 「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したリポジトリ内の **`extension` フォルダ**を選びます。`manifest.json`が入っているフォルダです。
5. ブラウザの拡張機能メニューから **Paper Margins** を開きます。

利用するだけなら、Node.jsのインストールやビルドは不要です。Chrome Web Storeには公開していません。展開したフォルダは削除せず保持してください。

### 既に使っている場合の更新

新しい `extension/` の**中身を、以前Chromeに登録したフォルダへ上書き**します。拡張機能を削除せず、拡張機能管理画面の↻を押して、PDF画面とChatGPT画面も再読み込みしてください。

以前の配布ZIPでフォルダ名が `paper-margins` だった場合も、その登録済みフォルダへ中身を上書きします。拡張機能を削除すると、その拡張機能に保存したデータも失われます。更新前に「バックアップ」で保存しておくと安心です。

## 基本の使い方

1. 「PDFを開く」で論文を選びます。ページは縦に並び、スクロールで読み進められます。
2. 本文をドラッグして選びます。数式・図は「数式・図を囲む」で範囲を選びます。
3. 質問を書き、「ChatGPTで質問する」を押します。
4. ChatGPT側のPaper Marginsパネルで「質問を入力」、または「質問＋選択画像を入力」を押します。
5. 入力欄の質問・画像を確認し、**ChatGPTの送信ボタンは自分で押します**。
6. 保存した会話は、PDF上の色付き箇所や注釈パネルから読み返せます。

論文全体も参照させたい場合は、PDF側の質問欄で **「PDF本体も添付する（原本）」** にチェックしてから「ChatGPTで質問する」を押します。ChatGPT側の「質問＋PDFを入力」で原本PDFを添付します。数式・図の選択画像がある場合は一緒に添付します。**PDF名とアップロード完了を確認して、自分で送信してください。**

チェックは初期状態でオフです。チェックなしならPDF本体を読み出して添付する処理は行いません。添付するのは元のPDFで、Paper Marginsで追加した手書き・質問回答の付録は含みません。アップロード自体はChatGPTのサービスにPDF全体を渡す操作です。自動添付を確認できない場合は、連携パネルの「原本PDFを保存して手動添付」を使えます。

### 保存されないとき

ChatGPT側パネルの「最新の回答を保存」を押します。回答を読み取れない場合は、開いた「回答」欄へChatGPTの回答をコピーして貼り付け、**「貼り付けた回答を保存」**を押してください。質問を書き直すこともできます。既存の回答を使えるので、もう一度質問を送る必要はありません。

更新やブラウザ再起動で接続が切れた場合は、ChatGPT画面でAlt＋Shift＋Pを押してパネルを表示し、「既存の回答を注釈へ保存」で保存先を選び、「接続して最新の回答を保存」を押します。PDF側の「質問・回答を手入力で保存」からも追加できます。

### ChatGPT側のパネルを表示する

普通にChatGPTを開いたときはPaper Marginsパネルを表示しません。PDFから「ChatGPTで質問する」で接続したタブに表示します。既存の回答を保存したい場合は、ChatGPT画面で **Alt＋Shift＋P** を押してパネルを表示し、「既存の回答を注釈へ保存」で保存先を選べます。

同じショートカットで完全に非表示にもできます。この表示切り替えは接続を解除しないため、接続中の自動保存は続きます。「連携を終了」では保存を止め、パネルも消します。ショートカットはChromeの `chrome://extensions/shortcuts` で変更できます。

### 注釈パネルを閉じる

PDF側のパネル右上の **「閉じる ×」**、または **Escキー**で閉じます。上部の「注釈」で開き直せます。ChatGPT側のパネルは右上の「−」で折りたためます。

ロゴ・ファイル名・操作欄の高さを抑え、論文の表示領域を広くしています。

## 複数のPDFをタブで開く

- 上部の「＋ 新しいタブ」を押し、開いたタブで別のPDFを選びます。
- 論文一覧の「↗」で、保存済みのPDFを新しいタブで開けます。論文名をCtrl＋クリック・中クリックしても開けます。
- 「PDFを開く」で複数ファイルを選択できます。最初のPDFを現在のタブで、残りを新しいタブで開きます。既にPDFを表示している場合は、選んだPDFを新しいタブへ開きます。
- タブのタイトルにPDF名を表示し、再読み込み後も同じPDFを開きます。表示ページ・質問欄はタブごとに独立し、書き込み・注釈は対応するPDFへ保存します。

同じPDFの手書きを複数タブで同時に変更して保存が競合した場合は、他のタブの保存を上書きせずエラーを表示します。そのタブを再読み込みすると保存済みの最新版を開けます。

## 手書きと自動保存

上部の「ペン」を押すと、PDF上にマウス・ペンで描けます。ビューア内のペンアイコンの設定で色・太さ・不透明度を変更できます。書き込んだ後に自動保存し、画面下部に「書き込み：保存中…」「書き込み：保存済み」を表示します。「書き込みを保存」でも保存できます。保存に失敗した場合は失敗を表示し、ボタンで再試行できます。保存済み表示を確認してから閉じてください。

「文章を選択」で質問する操作へ戻れます。「消しゴム」を押して消したい線をクリックすると、その線全体を削除します。削除も自動保存されます。「元に戻す」で直前の書き込み・削除を取り消せます。質問・回答の保存は従来どおりです。バックアップには手書き付きPDFも含みます。元のPDFは別に保持し、既存の質問注釈との対応を保ちます。

Chrome拡張のPDF Viewerそのものを呼び出すのではなく、同じPDF.jsの標準ビューアを同梱しています。PDF Viewerの追加インストールは不要です。

注釈を開くと、論文と注釈が重ならないよう表示領域を自動で分けます。通常は左右、特に狭い画面では上下に配置します。拡大したPDFは論文側の枠内でスクロールでき、「幅に合わせる」を選んでいる場合は利用できる幅に合わせて表示を調整します。

## 注釈付きPDFの読み方

「注釈付きPDF」で手書きを含めて書き出します。会話がある場合は、元のページに緑の番号を付け、PDF末尾に「注釈と会話」のページを追加します。質問・回答・選択箇所の全文を、コメント欄を開かずに読めます。長文は自動で改ページし、日本語のフォントも埋め込みます。

本文の番号をクリックすると対応する注釈へ移動し、注釈の見出しをクリックすると元のページへ戻れます。リンク非対応のPDFビューアーでも、末尾のページへ移動して内容を読めます。以前に書き出したPDFは変わらないため、更新後に再度書き出してください。

付録ではMarkdown・LaTeXを保存された文字列として掲載します。拡張機能の画面内のような数式の組版ではありません。フォントにない特殊文字は `[U+XXXX]` 表記で残し、元の文字列はコメントにも保持します。

## データ・権限

PDFはIndexedDB、注釈は拡張機能のローカル保存領域に保存します。別端末への自動同期はありません。バックアップJSONには元のPDF・書き込み付きPDF・会話を含みます。旧版のバックアップも復元できます。

ChatGPTで送信する内容は、通常どおりChatGPTのサービスで処理されます。拡張機能は独自の外部APIへPDFや会話を送信しません。APIキーを読み取る機能もありません。

| 権限 | 用途 |
| --- | --- |
| `storage` / `unlimitedStorage` | PDF・注釈・会話の保存 |
| `clipboardWrite` | 質問や切り抜き画像のコピー |
| `chatgpt.com` / `chat.openai.com` | 入力補助、連携パネル、接続した会話の取得 |

記録はPDFの注釈に接続したChatGPTタブで行います。「連携を終了」で止められます。別の会話への移動を検出した場合も、自動保存を停止します。

## 現在の制限

ChatGPTの画面構造に依存するため、自動入力・PDF／画像添付・回答取得が失敗することがあります。実際のChatGPT画面で回答を取得できなかった報告があり、**自動保存がすべての画面で動くことは確認できていません**。貼り付け保存を併用してください。

画像が入力欄に見えない場合は「選択画像をコピー」でコピーして貼り付けるか、「画像を保存」でPNGを添付できます。保存の調査には「診断ファイルを保存」が使えます。診断は要素の種類・クラス・件数などを記録し、会話本文や入力欄の値は含めません。

スマートフォンには対応していません。スキャンPDFは画像の範囲選択を使います。別版PDFへの注釈の自動移動や、暗号化PDFへの注釈付きPDF出力には対応していません。

確認済みの範囲と、模擬環境での確認である点は[検証記録](docs/VALIDATION.md)に記載しています。

## 開発・確認

Node.js **22以降**を使用します。

```sh
npm ci
npm test
npm run check
```

ブラウザで確認する場合：

```sh
npx playwright install chromium
npm run test:browser
```

ブラウザ確認では拡張APIをテスト用実装に置き換え、ChatGPTの模擬画面を使います。実際のChatGPTへメッセージを送信するテストではありません。既存のChromiumを使う場合は `CHROMIUM_PATH` で実行ファイルの絶対パスを指定できます。

配布ZIPはPython 3の標準ライブラリで作成できます。

```sh
python scripts/package.py
```

`dist/paper-margins-v1.3.1.zip` に、読み込み用フォルダと説明書を作成します。テスト出力やZIP、利用者のPDF・会話データはGitで管理しません。
