# ユーザーガイド

この拡張機能の独自コードと本ガイドは、ユーザーの指示に基づいてGPT（ChatGPT / Codex）が作成・修正しました。

インストール・更新については[README](../README.md)を参照してください。

## ChatGPT側の表示

普通にChatGPTを開いたときはパネルを表示しません。PDFから質問して接続したときに表示します。既存の回答を注釈へ保存したい場合は、ChatGPT画面でAlt＋Shift＋Pを押してパネルを表示してください。

Alt＋Shift＋Pでもう一度非表示にできます。非表示だけなら接続中の自動保存は続きます。「連携を終了」では保存を止めてパネルを消します。

## パネルの開閉とスクロール

注釈パネル右上の「閉じる ×」かEscで閉じ、上部の「注釈」で開き直せます。質問の下書きや保存済みの会話は消えません。PDFと注釈は、それぞれの枠内でスクロールします。ページ番号を入力して直接移動することもできます。

## 既存の回答を保存する

ChatGPT側パネルの「既存の回答を注釈へ保存」で保存先のPDF・ページ・質問を選び、「接続して最新の回答を保存」を押します。接続中なら「最新の回答を保存」を押してください。

自動で本文を読み取れない場合は、ChatGPTの回答のコピーボタンでコピーし、Paper Marginsパネルの「回答を貼り付けて保存 / 保存できない場合」を開きます。「質問」を確認し、「回答」へ貼り付けて「貼り付けた回答を保存」を押します。質問の再送信は不要です。

書き込みに成功してから保存完了を表示します。失敗した場合、貼り付けた本文は残ります。PDF側の「＋ 会話を貼り付け」からも会話を追加できます。

## 画面構造の診断

ChatGPT側パネルの「診断ファイルを保存」で `paper-margins-diagnostics.json` を出力します。会話本文や入力欄の値、HTML全文を含めず、画面の要素の種類・クラス・件数・親子構造を記録します。自動取得に失敗する画面を調査するために使います。

## 使い方

1. 「PDFを開く」で読みたい論文を選びます。PDFは端末内に保存されます。ページは縦に並ぶので、スクロールして読み進めます。
2. 本文をドラッグして選択すると、右側に質問欄が開きます。
3. 数式・図を選ぶ場合は「数式・図を囲む」を押してから範囲をドラッグします。注釈の選択範囲は1ページ内に収めてください。
4. 質問を入力し「ChatGPTで質問する」を押します。PDFとChatGPTが別ウィンドウで並びます。
5. ChatGPTの右上に現れるPaper Marginsパネルで「質問を入力」を押します。数式・図の範囲選択では「質問＋選択画像を入力」を押します。
6. 入力欄に質問と選択画像があることを確認して、**自分でChatGPTの送信ボタンを押します**。自動添付できなかった場合は、パネルの案内に従って画像を貼り付けてください。
7. 回答後、質問・回答がPDFの該当箇所に保存されます。続けて質問すると、その箇所の会話に追加されます。
8. PDFの「注釈」ボタンやPDF上の色付き箇所を押すと、保存された会話を読み返せます。
9. 別の箇所について聞くときは、その箇所を選択し直して「ChatGPTで質問する」を押します。新しい会話として開きます。

自動保存が働かない場合は、回答終了後に「最新の回答を保存」を押してください。ChatGPTの画面構造が変わって連携が動かない場合でも、PDF側の「質問・回答を手入力で保存」で会話を貼り付けられます。

## 参照する論文と数式

質問に付けるのは**選んだ文章、PDFページ番号、論文のファイル名**です。論文全体はChatGPTに自動送信されません。論文全体を参照してほしい場合は、ChatGPTにPDFを添付してください。

数式・図を囲むと、その範囲のPNGを質問時に作成して保存します。PDFにテキスト情報があれば、範囲内の文字も質問に含めます。数式の配置・記号は選択画像を参照してください。画像の自動添付は画面にあるアップロード欄や貼り付け処理を使い、添付されたファイル名を確認できない場合は画像コピー・手動添付を案内します。実際のChatGPT画面との接続は、この作成環境では未確認です。

ChatGPTの数式は、画面にLaTeX情報が含まれる場合はLaTeXとして保存し、注釈内で数式表示します。回答の文章は安全のためテキストとして保存します。Markdownの見出し・表・コードブロックは文字として表示します。

## 注釈とバックアップ

- 注釈のタグ欄に `群論, 導出, 要復習` などを入力できます。タグ、質問、回答、選択文章を検索できます。
- 「バックアップ」でPDF本体と全論文の注釈をまとめたJSONを書き出せます。「復元」で戻せます。
- 同じPDFはファイルの内容から識別するため、再度開いても注釈と対応します。別バージョンのPDFへの自動移動はしません。
- 「注釈付きPDF」で質問・回答をPDFのコメントとして書き出せます。コメント表示に対応したPDFアプリで開いてください。本文への直接の書き込みや、回答全文をページ余白へ印刷する方式ではありません。
- 別端末への自動同期はありません。バックアップで移してください。
- 拡張機能を削除すると保存データも失われます。削除前にバックアップしてください。

## 権限・費用

- この拡張機能自身のAPI課金、サーバー利用料はありません。独自サーバーや外部APIにPDF・会話を送信しません。
- ChatGPTで送信した内容は、通常どおりChatGPTのサービスで処理されます。
- `storage` / `unlimitedStorage`：PDF・会話・注釈を端末内に保存するため。
- `clipboardWrite`：用意した質問をコピーするため。
- ChatGPTのサイト権限：連携パネルの表示と、対象の会話の保存のため。他のウェブサイトにはアクセスしません。
- 自動保存の対象は、この拡張機能から開いて対象箇所と紐づけたChatGPTウィンドウです。既存の全会話を取り込むことはありません。
- 「連携を終了」で記録を止められます。別の会話へ移動した場合も自動保存を停止します。ブラウザ再起動で連携状態は解除され、保存済み注釈は残ります。

## 動作環境と既知の制限

Chrome / Edge 142以降のデスクトップ版向けです。スマートフォン版には対応していません。ChatGPTへのログインが必要です。文章の選択にはPDFのテキスト情報が必要です。スキャンPDFは範囲選択を使ってください。パスワード付きPDFは閲覧時にパスワードが必要です。注釈付きPDFの書き出しでは暗号化PDFに対応しません。

ChatGPTの回答完了は画面の停止ボタンと文章更新から判定します。通信中断やUI変更で保存されない場合は、手動保存を使ってください。再生成・編集した回答は同じメッセージIDの場合、同じ会話記録を更新します。
