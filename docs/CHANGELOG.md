# 変更履歴

独自コードとドキュメントは、ユーザーの指示に基づいてGPT（ChatGPT / Codex）が作成・修正しています。

## 1.0.7 — 2026-10-14

- 画面全体が下へスクロールして空白が出る表示を修正。PDF・注釈・論文一覧の枠内でスクロール。
- GitHub用に拡張機能・テスト・ドキュメントを整理。

## 1.0.6 — 2026-10-14

- 注釈パネル内に「閉じる ×」を追加し、スクロール中も固定表示。
- Escで閉じる操作と、すべての画面幅での開閉に対応。

## 1.0.5 — 2026-10-14

- 自動取得に依存しない、回答の貼り付け保存欄を追加。
- 保存失敗時に入力内容を保持。
- 会話本文を含まない、画面構造の診断ファイル出力を追加。

## 1.0.4 — 2026-10-14

- 非表示の停止ボタンを生成中と判定する処理を修正。
- 選択した回答の保存と、既存の回答を注釈へ再接続する操作を追加。
- 実際のChatGPT画面では回答を取得できない報告があり、自動保存の対応には引き続き調査が必要。

## 1.0.3 — 2026-10-14

- 選択した数式・図の切り抜きPNGと範囲内の本文を質問に追加。
- 画像添付の補助、PNGコピー・保存を追加。
- 同じ会話のURL変更に伴う自動保存停止の判定を調整。

## 1.0.2 — 2026-10-14

- PDFを全ページの連続スクロール表示へ変更。
- 遠いページのキャンバスを解放し、ページへ戻った際に再描画。

## 1.0.1 — 2026-10-14

- ChatGPTの入力欄への質問挿入と確認を改善。
- 自動入力できない場合のコピー・手動貼り付けを案内。

## 1.0.0 — 2026-10-14

- PDF表示、本文・範囲選択、ChatGPT連携、ローカル注釈、検索、バックアップ・復元、PDFコメント出力の初版。
